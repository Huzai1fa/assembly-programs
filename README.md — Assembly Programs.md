# Assembly Language Programs

A collection of **Assembly Language programs** created for learning and practicing basic programming concepts using Assembly Language.

This repository contains simple programs covering **output, input, arithmetic operations, and basic number manipulation**.

## 📚 Programs

| # | Program | Description |
|---|---|---|
| 1 | `helloworld.asm` | Displays **Hello World** on the screen. |
| 2 | `newLine.asm` | Demonstrates printing or creating a new line. |
| 3 | `Taking2inputs.asm` | Takes two inputs from the user. |
| 4 | `Sum.asm` | Performs a sum operation. |
| 5 | `Subtract.asm` | Performs a subtraction operation. |
| 6 | `addingTwonumbers.asm` | Adds two numbers. |
| 7 | `Multiplication.asm` | Demonstrates multiplication. |
| 8 | `Multiplication2numbers.asm` | Multiplies two numbers. |
| 9 | `Dividing2numbers.asm` | Divides two numbers. |

## ⚙️ Assembly Environment

The programs are written in Assembly Language and use **8086/MASM-style syntax**.

For example, the programs can use structures such as:

```asm
.model small
.stack 100H

.data

.code
```

and DOS interrupts for input/output operations.

## 🎯 Purpose

The purpose of this repository is to practice Assembly Language programming and gradually build an understanding of low-level programming concepts.

The repository will be updated as new Assembly programs and exercises are created.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Huzai1fa/assembly-programs.git
```

Navigate into the repository:

```bash
cd assembly-programs
```

Open any `.asm` file in an Assembly-compatible development environment and assemble/run the program.
